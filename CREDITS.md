# Origine delle risorse

## Grafica e audio originali del progetto

- **20 sfondi**: illustrazioni create con OpenAI ImageGen appositamente per Dogana Booleana, da prompt originali. Nessuna immagine di altri giochi è stata riutilizzata. I file pronti per il sito sono WebP 900×1350; prompt e originali di lavorazione sono conservati separatamente dalla pubblicazione.
- **Personaggi e icone**: vettori SVG modulari originali nel file `docs/characters.mjs`. Gli accessori del personaggio e quelli del cartello condividono la stessa geometria. Nessuna emoji o libreria di personaggi esterna.
- **Effetti sonori e musica**: composizione/sintesi originale attraverso Web Audio in `docs/audio.mjs`; nessun campione audio esterno.
- **Interfaccia**: direzione grafica originale approvata per il progetto. Il riferimento a Papers, Please riguarda soltanto il ritmo delle decisioni: nessun asset, personaggio o interfaccia di quel gioco è incluso.

## Carattere Anton

Anton, dai [Google Fonts](https://github.com/google/fonts/tree/main/ofl/anton), distribuito con **SIL Open Font License 1.1**. Il font è incluso localmente: nessuna richiesta a Google viene fatta dal browser durante il gioco.

La licenza e i titolari originali sono riportati integralmente in `docs/assets/fonts/OFL-Anton.txt`. Il file del carattere è `docs/assets/fonts/Anton-Regular.ttf`.
